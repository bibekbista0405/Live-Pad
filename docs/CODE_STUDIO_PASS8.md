# Code Studio Pass 8 — collaboration, room join, and smooth UI

## Fixed

- Added a server-side Firebase custom-token guest-auth bridge for projects where Firebase Anonymous Auth is disabled.
- The guest UID is generated by the server; the browser never supplies an identity.
- Existing Firestore rules remain authenticated and continue to enforce public-room self-join, private-room membership, and role permissions.
- Room navigation now falls back to the local room descriptor when cloud verification is temporarily unavailable instead of incorrectly reporting that every room does not exist.
- Code Studio title bar was flattened into a stable three-column toolbar; the project title is no longer rendered as a floating card/pill.
- Landing page JavaScript/Motion hover/tap transforms were removed from the scroll surface.
- Landing feature content is deferred with `content-visibility` and the home scroll surface keeps stable layout/interaction behavior.
- Added Pass 8 regression tests for guest auth, room joining, header structure, and landing motion removal.

## Cloud authentication boundary

The custom-token route requires the LivePad server to have Firebase Admin credentials available to the runtime (for example Application Default Credentials or an equivalent server credential setup). If those credentials are unavailable, LivePad intentionally keeps its secure local/BroadcastChannel fallback rather than weakening Firestore rules.

Public teaching rooms can therefore be joined by code once the server can issue the guest token. Private/invite-only rooms still require membership and are not made public by this change.
